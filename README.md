## 📌 What is IdeaForge AI?

**IdeaForge AI** is a complete **Agentic AI application** that helps entrepreneurs, students, researchers, and startup founders generate **innovative, validated business ideas** using a **5-agent AI pipeline** powered by **IBM Granite Models** on **IBM watsonx.ai Studio**.

---

## 🤖 Agentic AI Architecture

```
User Input (Text + Image Description + Voice Note)
        │
        ▼
┌─────────────────────────────────┐
│   Master Orchestrator Agent     │
└─────────────────────────────────┘
        │
        ├──► 🔍 Agent 1: Knowledge Discovery
        ├──► 💡 Agent 2: Idea Generation
        ├──► 📈 Agent 3: Trend Forecasting
        ├──► ⚖️  Agent 4: Feasibility Analysis
        └──► 🚀 Agent 5: Innovation Strategy
        │
        ▼
📊 Innovation Intelligence Report
```

## ✨ Key Features

| Feature | Description |
|---|---|
| 🤖 **5 AI Agents** | Specialized agents working in sequence |
| 🧠 **IBM Granite** | ibm/granite-3-8b-instruct model |
| 🎙️ **Multimodal Input** | Text, Image Description, Voice Note |
| 📊 **7-Tab Dashboard** | Ideas, Trends, Feasibility, Strategy, Idea Map |
| ⭐ **Top Idea Picker** | AI recommends highest-impact idea |
| 🌐 **Live Deployed** | Hosted on Render.com, accessible 24/7 |

## 🛠️ Tech Stack

- **AI Model:** IBM Granite 3 · 8B Instruct
- **Platform:** IBM watsonx.ai Studio
- **Backend:** Python + Flask
- **Frontend:** Bootstrap 5 + Vanilla JS
- **Deployment:** Render.com (Free Tier)
- **Server:** Gunicorn

---

## ⚙️ Setup & Run

```bash
pip install flask ibm-watsonx-ai requests gunicorn
export WATSONX_API_KEY="your-api-key"
export WATSONX_PROJECT_ID="your-project-id"
export WATSONX_URL="https://au-syd.ml.cloud.ibm.com"
python app.py
```
